## 1. 【確定事項】審判ルートは期限切れ → 再出願で進める

## 2. なぜ拒絶されたのかを特定する（現状確認）

再出願・審判のどちらを選ぶにせよ、**拒絶理由の特定が出発点**です。

### 2-0. 「却下」だったのか「拒絶」だったのかを切り分ける（重要）

今回は「**却下**」と聞いています。日本の商標実務では、両者は意味が異なります。

| 種類 | 意味 | よくある原因 | 再出願での示唆 |
| --- | --- | --- | --- |
| **手続却下 / 出願却下** | 手続き上の不備で門前払い | 補正命令への未応答、**手数料の未納**、書類の重大不備、出願人の連絡不通 など | 手続きを正しく行えば**通る見込みが高い**。中身の問題ではない可能性大 |
| **拒絶査定** | 審査内容で登録不可と判断 | 識別力なし(3条)、先行類似商標(4条1項11号) など | 表記や指定商品の作り直しが必要 |

> **「Webサイトを削除したのとほぼ同時に却下」**という経緯は、手続却下（応答・連絡不通や手数料関連）を示唆する可能性があります。
> サイトに紐づくメールアドレスへ特許庁からの**補正指令や通知が届いていたのに受け取れず、応答期限切れで却下**——というパターンが典型です。
> もしこれが原因なら、今回は連絡先を確実にして手続きすれば登録できる可能性が高いです。J-PlatPatの経過情報で要確認。

### 2-1. 出願内容を調べる
- [ ] **J-PlatPat**（https://www.j-platpat.inpit.go.jp/）で「ZAZOO」または出願番号を検索
- [ ] 出願番号・区分（指定商品・役務）・出願経過を記録する
- [ ] 却下理由（**却下の決定書 / 拒絶理由通知書**）の本文を入手し、理由を確認する

### 2-2. よくある拒絶理由と対応方針

| 引用条文 | 内容 | 主な対応 |
| --- | --- | --- |
| 3条1項3号 | 商品の品質・産地等を**記述的**に表すだけ | 図形ロゴ化／使用による識別力獲得(3条2項)の主張／指定商品の見直し |
| 3条1項6号 | その他**識別力がない** | ロゴ・デザイン要素の付加／指定商品の見直し |
| **4条1項11号** | **先行する同一・類似の登録/出願商標**があり、指定商品も類似 | 最頻出。先行商標の特定→指定商品の限定／非類似化／コンセント(同意書)／別表記の検討 |
| 4条1項各号 | 公序良俗、著名商標との混同 等 | 個別対応（要弁理士相談） |

> **4条1項11号（先行商標との抵触）**が最も多い拒絶理由です。先行する「ZAZOO / ザズー」等の類似商標が既に登録・出願されていないか、J-PlatPatで確認してください。これが原因の場合、**同じ内容で再出願しても再び拒絶**されます。指定商品・役務の調整や表記の工夫が必要です。

## 4. 再出願の準備チェックリスト（ルートB）

### 4-1. 出願戦略の設計
- [ ] **商標の表記を決める**：文字「ZAZOO」単体か、ロゴ（図形＋文字）か
      （識別力で拒絶された場合、ロゴ化で通りやすくなることがある）
- [ ] **指定商品・役務（区分）を決める**：Amazonで実際に販売する商品に合わせる
      （例：化粧品=第3類、衣料=第25類、玩具=第28類 など。商品に合った区分を選ぶ）
- [ ] **先行商標調査**：J-PlatPatで同一・類似商標の有無を確認（4条1項11号対策）

### 4-2. 出願手続き
- [ ] 出願書類を作成（電子出願推奨。または書面）
- [ ] 特許庁へ出願

### 4-3. 費用の目安（特許印紙代・2026年時点の一般的水準。要最新確認）

| 手続き | 金額の目安 |
| --- | --- |
| 出願料 | 3,400円 + 区分数 × 8,600円 |
| 登録料（10年一括） | 区分数 × 32,900円 |
| 登録料（5年分割・前期） | 区分数 × 17,200円 |
| 更新登録料（10年） | 区分数 × 43,600円 |

- 弁理士に依頼する場合は、上記とは別に**手数料（出願時・登録時で数万円〜）**がかかります。

### 4-4. 期間の目安
- 通常審査：出願から登録まで **おおむね半年〜1年程度**
- 急ぐ場合は **早期審査**の活用を検討（要件あり。Amazon出品実績などが事情説明に使えることがある）

## 5. Amazonブランド登録への再登録

商標が **登録（registered）** されたら、再登録に進みます。
（※出願中(pending)の段階では、原則 Amazon IP Accelerator 経由など特定ルートを除き登録できません）

- [ ] 登録番号・登録証を入手
- [ ] https://brandregistry.amazon.com/ にログイン
- [ ] 新規ブランド登録申請を提出（ブランド名・商標登録番号・商品画像・ブランドロゴ等）
- [ ] 審査・認証コードによる確認に対応
- [ ] 登録完了後、A+コンテンツ／ブランドストア／侵害通報ツール等の特典を再有効化

> Amazonの「IP Accelerator」を使うと、提携弁理士経由で**出願中でも一部のブランド登録特典**を先行利用できる場合があります。早く保護を始めたい場合の選択肢です。

## 6. 今後のブランド保護（再発防止）

- [ ] **更新期限の管理**：登録は10年ごとに更新が必要。期限を台帳・カレンダーで管理する
      （今回の解除原因が「更新漏れ」型のケースでは特に重要）
- [ ] Amazonからの通知メールを見逃さない運用を作る（担当者・転送設定）
- [ ] 販売拡大国（米国USPTO・EU等）での商標取得も計画的に検討
- [ ] 類似ドメイン・SNSアカウント・模倣品の定期チェック

## 7. 次のアクション（推奨順 / 再出願ルート）

1. **J-PlatPatで過去の出願を特定**し、「却下」か「拒絶」かと理由を確認する
2. 却下理由をふまえ、**今回の出願内容を設計**（表記＝文字/ロゴ、指定区分、先行商標調査）
3. **連絡先（メール・住所）を確実なものに**して、特許庁からの通知を受け取れる体制にする
   （前回がサイト削除に伴う連絡不通／手続却下なら、ここが再発防止の肝）
4. **弁理士に相談**（指定商品設計・先行商標調査・出願代理）または自力で電子出願
5. 出願 → 審査対応（必要なら早期審査）→ **登録**
6. 登録後 → **Amazonブランド登録へ再申請**（第5章）
