# ZAZOO 商標登録 出願手順（日本・特許庁）

> **免責事項**：一般的な手順の整理です。法的助言ではありません。料金・制度は変わるため、
> 特許庁(JPO)の最新情報で必ず確認してください。複雑な場合は弁理士への依頼を推奨します。

この手順書は「**再出願（新規出願）**」を自分で／弁理士に依頼して行う前提の実務手順です。

---

## STEP 0. 出願方法を選ぶ

| 方法 | 難易度 | 費用感 | 向いている人 |
| --- | --- | --- | --- |
| **A. 弁理士に依頼** | ★（楽） | 特許印紙代＋代理手数料（出願時 数万円〜＋登録時） | 確実に通したい／前回却下されている今回はおすすめ |
| **B. 自分で電子出願** | ★★★ | 特許印紙代のみ | コスト最優先、手続きに慣れている |
| **C. 自分で書面出願** | ★★ | 特許印紙代＋電子化手数料 | PC環境を整えたくない |

> **まずは無料の公的窓口に相談を。**
> 過去に **INPIT 滋賀県知財総合支援窓口（無料）** の支援を受けていました。前回が手続ミスでの
> 却下なら、同窓口の伴走で **B（自分で電子出願）でも十分通せる**可能性が高いです。
> コストを抑えたいなら「窓口に相談しながら自力出願（B）」、確実性最優先なら「弁理士依頼（A）」。
> 以下は自分で出願する場合（B/C）も含めた全手順です。

## STEP 1. 事前準備（出願前の調査・設計）

### 1-1. 過去の出願を確認
- [ ] J-PlatPat（https://www.j-platpat.inpit.go.jp/）で「ZAZOO」を検索
- [ ] 過去出願の番号・区分・却下/拒絶理由を記録（→ `trademark-recovery.md` 参照）

### 1-2. 商標の表記を決める
- [ ] **文字商標**（「ZAZOO」を標準文字で）か、**ロゴ商標**（デザイン化した図形）か
- [ ] ロゴの場合は商標見本の画像データ（推奨：白黒 or カラー、規定サイズ）を用意

### 1-3. 指定商品・役務（区分）を決める ★最重要
本件 ZAZOO（ペットフード／飼料系）の想定区分：

| 区分 | 内容 | 指定商品・役務の例 |
| --- | --- | --- |
| **第31類** | 飼料・農産物等 | 「愛玩動物用飼料（ペットフード）」「飼料」など |
| **第35類** | 小売役務（小売等役務） | 「飼料の小売又は卸売の業務において行われる顧客に対する便益の提供」等 |

- [ ] Amazonで実際に売る／売る予定の商品を具体的にリストアップ
- [ ] 上記2区分で過不足ないか確認（自社で小売・通販するなら第35類が有効。製造販売のみなら第31類中心 など）
- [ ] **類似商品・役務審査基準**や J-PlatPat の「商品・役務名検索」で正式名称を確認
- [ ] 区分数が増えるほど費用が上がるので、必要な区分に絞る
- [ ] ※指定商品・役務の正式な記載は **INPIT 窓口に相談して確定**するのが安全

### 1-4. 先行商標調査（拒絶回避）
- [ ] J-PlatPat の「商標検索」で同一・類似（称呼「ザズー」等）の登録/出願を確認
- [ ] 同一区分に先行する類似商標があれば、指定商品の調整・表記の工夫を検討

## STEP 2. 願書（商標登録願）の作成

電子・書面いずれも記載内容は同じ。主な記載事項：

```
【書類名】       商標登録願
【整理番号】     （自分の管理番号。任意の英数字）
【提出日】       令和○年○月○日
【あて先】       特許庁長官 殿
【商標登録を受けようとする商標】
                 （標準文字の場合は↓を記載）
【標準文字】     （※標準文字制度を使うとき。ロゴの場合は商標見本を貼付）
                 ZAZOO
【指定商品又は指定役務並びに商品及び役務の区分】
  【第３類】
  【指定商品（指定役務）】　化粧品，せっけん類　…（正式名称で列挙）
  【第２５類】
  【指定商品（指定役務）】　被服，…
【商標登録出願人】
  【識別番号】   （取得済みなら記載）
  【氏名又は名称】（個人名 or 法人名）
  【住所又は居所】（連絡が確実に取れる住所）
（代理人がいる場合）
【代理人】
  【識別番号】 …
```

- [ ] 願書を作成（電子出願ソフトのひな型 or 書面様式を使用）
- [ ] **連絡先（住所・メール）を確実に受け取れるものにする**（前回却下の再発防止）

## STEP 3-A. 弁理士に依頼する場合

1. [ ] 弁理士／特許事務所を選定（商標に強い事務所、Amazon IP Accelerator提携事務所も選択肢）
2. [ ] ブランド名・ロゴ・販売商品・前回の経緯を伝える
3. [ ] 区分設計・先行商標調査を依頼
4. [ ] 見積もり確認 → 出願代理を依頼
5. [ ] 以降の特許庁とのやりとり（拒絶理由通知への応答含む）は弁理士が代行
→ STEP 6（審査対応）へ

---

## STEP 3-B. 自分で「電子出願」する場合

1. [ ] **申請人利用登録 → 識別番号の取得**（特許庁・電子出願ソフトサポートサイト）
2. [ ] **電子証明書を取得**
       - 個人：マイナンバーカード＋ICカードリーダ、または民間認証局の証明書
       - 法人：商業登記に基づく電子証明書 等
3. [ ] **「インターネット出願ソフト」をインストール**（Windows/Mac、サポートサイトから）
4. [ ] 願書（HTML形式）を作成 → ソフトに読み込み
5. [ ] **オンライン提出**
6. [ ] **出願料の納付**（予納／現金納付／口座振替／指定立替納付（クレジット）等）
→ STEP 6 へ

## STEP 3-C. 自分で「書面出願」する場合

1. [ ] 願書を所定様式で作成・印刷
2. [ ] **特許印紙**を購入し願書に貼付（消印しない）
3. [ ] 特許庁へ郵送（書留推奨）または窓口持参
4. [ ] 後日、**電子化手数料**の納付書が届く → 納付
       （目安：1,200円＋700円×書面枚数）
→ STEP 6 へ

## STEP 4. 出願料（特許印紙代）の目安

> 2026年時点の一般的水準。**必ず特許庁の最新の料金表で確認**してください。区分数で変動します。

| 手続き | 金額 |
| --- | --- |
| **出願料** | 3,400円 ＋（区分数 × 8,600円） |
| **登録料**（10年一括） | 区分数 × 32,900円 |
| 登録料（5年分割・前期分） | 区分数 × 17,200円 |
| 更新登録料（10年） | 区分数 × 43,600円 |

- 例）**本件想定の2区分（第31類＋第35類）・10年**の場合：
  - 出願時：3,400 ＋（2 × 8,600）＝ **20,600円**
  - 登録時：2 × 32,900 ＝ **65,800円**
- 弁理士依頼時は上記＋代理手数料（INPIT窓口の相談自体は無料）

## STEP 5. 出願後の流れ（審査）

```
出願
 → 方式審査（書類の形式チェック。不備があれば補正指令 → 期限内に応答）
 → 実体審査（識別力・先行商標などの審査。通常 数ヶ月〜）
 → ┌ 問題なし → 登録査定
   └ 問題あり → 拒絶理由通知 → 期限内に【意見書】【補正書】で応答
                 → 解消 → 登録査定 ／ 未解消 → 拒絶査定
 → 登録査定後30日以内に【登録料】を納付
 → 設定登録（商標権発生）→ 登録証発行・商標公報掲載
```

### この段階での最重要ポイント（前回の再発防止）
- [ ] **特許庁からの通知（補正指令・拒絶理由通知）を必ず受け取り、期限内に応答する**
- [ ] 通知の宛先（住所・メール）を常に最新・有効に保つ
- [ ] 応答期限（拒絶理由通知への意見書は通常、発送日から国内40日が目安）を管理

### 期間短縮
- [ ] 急ぐ場合は **早期審査**の申請を検討（要件あり。Amazon出品実績等が事情説明に使える場合がある）

---

## STEP 6. 登録 → Amazonブランド登録へ再申請

1. [ ] 登録査定 → 登録料納付 → **設定登録（商標権成立）**
2. [ ] 登録番号・登録証を入手
3. [ ] https://brandregistry.amazon.com/ にログイン
4. [ ] 新規ブランド登録申請（ブランド名・商標登録番号・ロゴ・商品画像等）
5. [ ] 認証コード等の確認に対応 → 登録完了 → ブランド特典を再有効化

> 早く保護を始めたい場合は **Amazon IP Accelerator**（提携弁理士経由で出願中でも一部特典を先行利用）も検討。
